Fonts bundled for the build-time OG image generator (scripts/seo/og.mjs) and the Telegram app
icon (scripts/telegram/app-icon.mjs).

- Manrope-SemiBold.ttf
  Copyright 2018 The Manrope Project Authors (https://github.com/sharanda/manrope)
  Licensed under the SIL Open Font License, Version 1.1 — see OFL-Manrope.txt.

  MODIFIED: this is a static instance of the variable font ofl/manrope/Manrope[wght].ttf from
  https://github.com/google/fonts, pinned to wght=600 (the brand's display weight). The upstream
  variable font defaults to wght=200 and resvg rasterizes a variable font at its default instance,
  so shipping the variable file would have set every social card in ExtraLight. The instance was
  cut with fontTools.varLib.instancer; no outlines were redrawn. The OFL permits modification and
  redistribution provided the software is not sold on its own; Manrope declares no Reserved Font
  Name, so the family name is kept.
