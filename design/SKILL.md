If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key rules: весь текст на русском, тон тёплый («ты», без сержанта); интерфейс строго ч/б (фон #0f0f11, белая «бумага» для профиля/подложек); единственный цвет — цвет программы: марафон #FF7A1A, йога #A8C8FF, новичкам #F2F52D (один экран — один цвет; цвет красит обложку, прогресс и номера — но НЕ кнопки); кнопки только ч/б (primary — белая заливка/чёрный текст); скругления по CHANGELOG §8 (карточки 24, плитки 20, контролы 12), а по §10 факт-не-контрол — пилюля («12 баллов», приз), человек и ранг — круг; иконок почти нет — типографские/кодовые глифы (→ ✓ × 01 [ ] ›_) в Unbounded; Phosphor fill мелко только где глиф не читается (play/pause); таб-бар — плавающая стеклянная капсула с иконками и скользящей подсветкой (§10); мера стиля — прототип ui_kits/app-v2: минимум текста, крупные числа, кольца и пилюли; дисплей Unbounded капс (800) с приёмами .t-echo/.t-stroke, текст Onest; кикеры капс .18em; фото — монохром + зерно, белый капс поверх; композиция асимметричная, редакционная; логотип «FORMA» — FOR 800 + MA 200, широкая F ×1.22 (компонент Logo), lockup «FORMA // Сергей Титов»; дисплей — весовой контраст 800+200 в одной строке вместо контура/эха.
