# Forma Design System — «Форма»

**Продукт:** «Форма» — приложение для кроссфита дома, которое подстраивается под человека. Слоган: **«Кроссфит дома, который подстраивается под тебя»**. Курсы для дома (с оборудованием и без), пожизненный доступ, видео к каждому упражнению, нагрузка растёт вместе с пользователем, принцип «объяснили → сделали → отдохнули».

**Платформы:** Telegram Mini App (мобайл, ~390px) + веб-лендинг.
**Тренер:** Сергей Титов — тёплый, человечный голос, техника важнее цифр. Lockup: «Форма × Сергей Титов».
**Владелец:** Анастасия (дизайнер), дорабатывает систему вручную.

**Источники:** доска Pinterest https://pin.it/33P5e0l4i + скриншоты пинов и макеты марафона Насти в `uploads/` (ч/б + серифная антиква + рукописные акценты — стиль марафона; Verdo/pace+ — стиль приложения). Кодовой базы и Figma нет.

## Направление (референсы: спорт-кампании Verdo/pace+, макеты марафона Насти)
Полностью ч/б интерфейс: чёрный #0f0f11, белая «бумага», монохромные полнокадровые фото. Широкий капс-дисплей Unbounded с blur-эхом и контурными строками. Единственный цвет в системе приходит из программы (курса): марафон — оранжевый, йога — голубой, новичкам — кислотный жёлтый. Один экран — один цвет.

### Эволюция (было → стало)
1. Цвет: пастельные акценты в UI → интерфейс строго ч/б; цвет только у программ (#F08A3C / #A8C8FF / #F2F52D).
2. Дисплей: Manrope → **Unbounded** (капс, 800/600) + приёмы `.t-echo` (blur-эхо) и `.t-stroke` (контур).
3. Скругления: 24px → **0px** везде (острая редакционная система); пилюли и glow убраны.
4. Профиль и светлые подложки: серый → чистый белый («бумага», --paper).
5. Фото: без изменений — монохром, зерно, белый капс поверх, защитный градиент.

## CONTENT FUNDAMENTALS
- Язык: только русский. Обращение на «ты», тёплое, без «сержанта» и без канцелярита.
- Голос Сергея: простой разговорный русский, забота о новичке. «Первая тренировка не должна тебя уничтожить — она должна заставить захотеть прийти на вторую».
- Техника важнее цифр: не давим рекордами, не стыдим. Никаких «СЖИГАЙ ЖИР», «НЕ ЛЕНИСЬ».
- Так: «Сегодня спокойно разберём присед. Смотри видео и повторяй в своём темпе». Не так: «ТЫ ОБЯЗАН выложиться на 100%!»
- Так: «Устал — отдохни. Вернёмся, когда будешь готов». Не так: «Пропустил день = слил прогресс».
- Регистр: предложения с обычной капитализацией; капс только в кикерах-лейблах.
- Эмодзи: не используются в UI; допустим 1 сдержанный эмодзи в соцсетях.
- Формула контента: «объяснили → сделали → отдохнули» — трёхшаговые структуры повсюду.

## VISUAL FOUNDATIONS
- **Композиция:** асимметрия и редакционная сетка: крупный капс-дисплей, вертикальные подписи, нумерация 01/02/03, hairline-линии вместо коробок; воздух важнее симметрии.
- **Цвет:** интерфейс ч/б — фон #0f0f11, поверхности #17171a/#1f1f24/#2a2a30, белая «бумага» #ffffff (профиль, маркетинг-подложки). Акцент интерфейса — белый.
- **Цвета программ (единственный цвет в системе):** марафон-игра #F08A3C, йога #A8C8FF, новичкам #F2F52D (--course-*). Правило: один экран — один цвет; он красит обложку курса, CTA, прогресс и номер текущего дня. Текст на цвете — всегда чёрный.
- **Тип:** Unbounded (капс) для дисплея, Onest для текста. Главный приём — весовой контраст в одной строке: толстое 800 + тонкое 200 («**Присед** без боли», «28 **дней**»). Кикеры: 10–11px, капс, трекинг .18em. `.t-echo`/`.t-stroke` — легаси, в новых макетах использовать вес 200.
- **Фото:** основа визуала — крупные полнокадровые фото людей (монохром, зерно), белый капс поверх, защита — тёмный градиент. В макетах стоят <image-slot> — перетащите фото прямо в превью.
- **Плашка-«прицел»:** ключевая статистика/факт — чёрная плашка с угловыми засечками (14px, 2px) в цвете программы по углам, без сплошной рамки. Использовать точечно, один прицел на экран.
- **Скругления:** 0px везде — карточки, кнопки, поля, плитки. Пилюль и glow нет. Круг — только у кнопки play поверх видео.
- **Тени:** почти нет; --shadow-paper для полароид-карточек на белом.
- **Анимация:** спокойные fades, ease-out cubic-bezier(.22,.61,.36,1), 150/280ms. Без bounce.
- **Hover:** осветление поверхности на шаг или opacity .85. Press: scale(.98).
- **Границы:** rgba-белый .10/.18 на тёмном; rgba-чёрный .14/.25 на бумаге. Hairline-линии — главный разделитель.
- **Блюр/прозрачность:** backdrop-blur только для таб-бара поверх контента.
- **Слои:** bg-0 → surface-1 → surface-2; на бумаге — чёрные врезки-карточки.
- **Фирменная графика:** фигурки-палочки в стиле чертежа: моно-линия 5px, stroke-linecap:butt, голова — квадрат 16×16 контуром, чёрный штрих в файле (на цвете программы и бумаге как есть; на тёмных поверхностях — filter:invert(1)) — assets/figures/.

## ICONOGRAPHY
- **Иконок почти нет.** Иерархия: 1) типографские/кодовые глифы — → ‹ › ✓ × 01 [ ] // ›_ 12′ (Unbounded 600, компонент `Glyph`); 2) **Phosphor FILL** с CDN `https://unpkg.com/@phosphor-icons/web` — только когда глиф не читается (play/pause, физические объекты), мелко 12–16px. В React — компонент `Icon` (components/core/Icon.jsx). Это осознанный выбор стиля (тонкая линия под пастель), собственного айкон-фонта у бренда нет.
- Иконки и глифы всегда ч/б, в цвета программ не красятся. Таб-бар — вообще без знаков: активный пункт крупный Unbounded, остальные мелкий капс.
- Логотип: «FORMA» — Unbounded, FOR 800 + MA 200 (толстое → тонкое), первая F расширена ×1.22, трекинг .05em, зазор F→O .16em. Компонент `Logo` (sergey — lockup «FORMA // Сергей Титов»). Иконка — широкая F на чёрном квадрате 0px. Только ч/б, латиница.
- Фигурки-палочки: assets/figures/*.svg — ЧЕРНОВИКИ, нарисованы с нуля как направление стиля; Анастасия заменит финальными.
- Эмодзи и unicode-иконки в UI не используются.

## Интенциональные добавления
- `Icon` (Phosphor fill, минимально) и `Glyph` (типографские знаки) — для плеера и меток; `Logo` — леттеринг FORMA.
