06

Как загрузить

Ролик

Назвать файл строго по id движения — burpee.mp4. Приложение ищет клип по имени, поэтому переименовывать ничего не надо.

Положить

В media/clips, затем npm run media:upload. Скрипт кладёт ролик в закрытый бакет и режет из него кадр в открытый.

Требования

Всё в docs/VIDEO.md. Без звуковой дорожки — ролики всё равно играют беззвучно и в цикле.
