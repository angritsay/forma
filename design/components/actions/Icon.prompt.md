Иконки почти не используются. Иерархия знаков «Формы»:

1. **Типографские/кодовые глифы** (предпочтительно): → ‹ › ✓ × 01 02 [ ] // ›_ 12′ — компонент `Glyph` или просто текст в Unbounded 600.
2. **Phosphor FILL** — только когда глиф не читается (play/pause, физические объекты). Мелко: 12–16px. Страница подключает `https://unpkg.com/@phosphor-icons/web`.

```jsx
<Glyph>→</Glyph> <Glyph>✓</Glyph> <Glyph size={14}>01</Glyph>
<Icon name="play" size={14} /> {/* fill по умолчанию */}
```

Иконки и глифы всегда ч/б, в цвета программ не красятся.
