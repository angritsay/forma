Кнопка — острый прямоугольник (4px), капс-лейбл с трекингом. primary — голубая заливка с тёмным текстом, secondary — поверхность с границей, ghost — прозрачная.

```jsx
<Button variant="primary" size="lg" icon="play" fullWidth>Начать тренировку</Button>
```

Размеры sm/md/lg = 40/48/56px (цель нажатия ≥44 — sm только для второстепенного). Press: scale(.98).
