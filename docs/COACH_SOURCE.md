# Sergey's beginner channel — source material

Verbatim extract of the `‼️НОВИЧКИ‼️` Telegram channel the owner exported: 38 workout
descriptions in his own words, and 215 video posts (145 unique clips).

This is reference material, not content the app reads. It is here because it is the only
written record of how he actually programmes for beginners, and because the videos carry no
captions — the order of these posts is the only clue to what each clip shows.

```

НОВИЧКИ ‼️
```
